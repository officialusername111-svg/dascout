## 1. Invite approval queue — BUILT, COMMITTED, NOT LIVE

An invited person creates an account, confirms it with a 6-digit code, and then **waits**. Nothing
grants a role until the owner presses Approve. Decline doubles as the **cancel** the product never
had.

**Two earlier designs were killed by a security review** — both promoted people automatically.
`docs/agent-runs/run-p7-invite-autoredeem.md` has the findings; read it before touching this
feature, because it is why a human sits at the end.

**The self-service "Accept invitation" door is retired.** `redeem_admin_invite` keeps its definition
and loses its `authenticated` EXECUTE grant, so restoring it is one statement. The invitation email
**no longer carries a token at all** — the secret is minted, read, discarded, and dies with the
request.

### What is required to make it live, in this order

   MCP. **It has never been executed anywhere** — desk-checked hard against the real schema, nothing
   found that would fail at apply, but never run.
2. **Run the suite.** Both red tests must go green **with no edits**. If either needs editing, that
   is a finding, not a fix.
3. **Deploy the code**, promptly — the retirement bites at apply time, so the old Accept links die
   before the new pages ship. Vercel takes ~20s.
4. **Change the Supabase email template** — owner action, cannot be done from here.
   `https://supabase.com/dashboard/project/kogpuuidawbmttyswvsx/auth/templates` →
   **Authentication → Emails → "Confirm signup"**. Keep `{{ .ConfirmationURL }}` **and** add
   `{{ .Token }}`; both come from the same token, so link and code both work and nothing breaks in
   either direction. Drop the link later, once a real signup has used the code.
5. **Walk `docs/TEST-PLAN-p9-approval-queue.md` §Group C** — ten numbered steps. **Do not skip

## 5. Traps that cost time, still true

- **The two-root path trap.** Prefix repo paths with `dascout/`. It has cost four sessions their
  opening tool calls.
- **A grant change and the code depending on it MUST ship together, in both directions.** Ten-minute
  outage on 2026-08-02. Grants that *widen* may land before the code; anything that *narrows* must
  land after it.
- **The admin form echoes what you submitted.** Asserting an input's value after Save proves
  nothing — it passes even when the write failed. Wait for the server's `.fmsg.ok` banner, or
  re-fetch.
- **PowerShell mangles UTF-8.** Do not round-trip source files through it.
- **`.pill` is absolutely positioned by default.** Any new admin surface rendering one inline needs
  the `position:static` override in `globals.css`.
- **Playwright needs `npm run build` first** and takes port 3000. `06-public-smoke` and
  `18-admin-redesign` are read-only and safe.
- **`web/AGENTS.md` is real.** Next.js **16.2.12**, not the Next in your training data.
- **Never run `npm audit fix --force`** — it downgrades Next to 9.3.3.
- **A full Vitest run leaves `zz-` residue.** This session's agents ran it enough times to leave 69
  listings and 162 events. Sweep at the end of any session with heavy test runs.
